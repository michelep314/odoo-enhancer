# odoo-enhancer

Estensione per Chrome che aggiunge funzioni di produttività a Odoo (`*.odoo.com`): barra di pulsanti, fogli ore, modifica rapida delle schede, priorità, ricerca rapida, sfondi e backup della configurazione.

- **Installazione:** `chrome://extensions` → Modalità sviluppatore → "Carica estensione non pacchettizzata" → questa cartella.
- **Strumenti e Novità:** icone al centro della barra in alto di Odoo; la freccia le comprime accanto alla chat (✨ = novità).
- **Storico delle versioni:** [CHANGELOG.md](CHANGELOG.md).
